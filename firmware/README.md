# Spine Smart — прошивка 0.1.1

Для ESP32-C3 SuperMini и датчиков MPU6050 / MPU6500. На проверенной плате датчик отвечает WHO_AM_I=0x70 (MPU6500). Это первая версия для проверки сборки: наклон измеряется относительно положения, которое ты сохранишь при калибровке. Работа без подключённого датчика предусмотрена: состояние `WAIT_SENSOR` означает «жду датчик».

## Что умеет

- Автоматически искать MPU6050 / MPU6500 каждые 3 секунды.
- Сохранять калибровку, порог наклона и задержку в памяти ESP.
- Определять устойчивый наклон: по умолчанию 15° в течение 10 секунд. Движение сбрасывает отсчёт; гистерезис 3° снижает переключения возле порога.
- Выдавать состояние по USB и Bluetooth LE.
- Управлять короткой вибрацией 150 мс с интервалом не менее 30 секунд при продолжающемся отклонении. После каждого перезапуска управление мотором нужно разрешать заново.

Измеряется наклон места крепления, а не изгиб всего позвоночника. Алгоритм использует сглаженный вектор ускорения, а гироскоп — для обнаружения движения. Порог и поведение ещё нужно проверить на собранном устройстве и при обычных движениях.

## Следующий шаг: подключение датчика

Сначала отключи USB и аккумулятор. Для первой проверки достаточно четырёх проводов:

| GY-521 | ESP32-C3 SuperMini |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO8 / 8 |
| SCL | GPIO9 / 9 |

INT пока не используется. Поддерживаются адреса 0x68 и 0x69. GPIO8/9 выбраны по схеме проекта; это также загрузочные выводы ESP32-C3, поэтому после монтажа нужно проверить обычное включение и вход в загрузчик. Светодиод на GPIO8 намеренно не мигает: этот вывод занят датчиком.

После подключения и подачи USB-питания ожидается `NEED_CALIBRATION`. Закрепи датчик в окончательном положении, выпрямись, отправь `calibrate` и стой спокойно около 3 секунд. При успехе будет `OK CALIBRATED`. После изменения крепления калибровку повторить.

## Команды по USB

Монитор последовательного порта: 115200 бод, окончание строки LF или CRLF. Определите текущий USB-порт на своём компьютере. Не открывай порт одновременно в нескольких программах.

| Команда | Действие |
| --- | --- |
| `status` | Состояние в формате JSON |
| `diag` | Текущие ускорения, вращение, адрес датчика и счётчик измерений |
| `bus` | Проверка адресов I2C на GPIO8/9 и уровней линий; останавливает импульс мотора |
| `stream off` / `stream on` | Остановить / включить ежесекундные сообщения |
| `zero gyro` | Коррекция нуля гироскопа: неподвижно держать 3 секунды; не сохраняет положение спины |
| `bias` | Показать сохранённую поправку гироскопа |
| `calibrate` | Сохранить текущее положение как ровное |
| `clearcal` | Удалить калибровку |
| `threshold 15` | Порог в градусах: от 5 до 45 |
| `delay 10` | Задержка в секундах: от 2 до 60 |
| `motor on` | Разрешить мотор до следующего перезапуска |
| `motor off` | Запретить мотор и остановить импульс |
| `motor test` | Импульс 150 мс, только после `motor on` |
| `selftest` | Проверить логику программы без датчика и мотора |
| `reboot` | Перезапустить ESP |
| `help` | Список команд |

Мотор управляется через GPIO3 и внешний транзисторный ключ. Напрямую к GPIO мотор не подключать. Перед его включением нужно сверить фактический транзистор, распиновку, защитный диод и схему питания. Проверка аккумулятора, зарядки и моторной цепи в эту USB-проверку не входит.

## Bluetooth LE

Имя: `SpineSmart-XXXX`. Это BLE-устройство, не обычный Bluetooth COM-порт. Мобильное приложение в этот комплект не входит.

- Сервис: `fa5e0001-3a93-4e9c-a5bc-5350494e4501`.
- Состояние: `fa5e0002-3a93-4e9c-a5bc-5350494e4501`, строка UTF-8, чтение и уведомления.
- Угол: `fa5e0003-3a93-4e9c-a5bc-5350494e4501`, float32 little-endian, чтение и уведомления. NaN означает отсутствие измерения.

Настройки и мотор по Bluetooth пока не управляются. Радиосвязь с телефоном нужно проверить отдельно.

## Исходники и повторная сборка

Открыть `SpineSmart/SpineSmart.ino` в Arduino IDE с пакетом **esp32 by Espressif Systems 3.3.2**. Дополнительные библиотеки не нужны.

- Board: ESP32C3 Dev Module.
- USB CDC On Boot: Enabled.
- Flash Size: 4 MB.
- Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS).
- CPU: 160 MHz; Flash: QIO, 80 MHz.
- Core Debug Level: None.
- Erase All Flash: Disabled — сохраняет настройки.

FQBN для Arduino CLI:

```text
esp32:esp32:esp32c3:CDCOnBoot=cdc,FlashSize=4M,PartitionScheme=huge_app,UploadSpeed=921600
```

Скомпилированные файлы и резервные копии памяти платы в публичный репозиторий не включены. Перед любым восстановлением нужно сверять модель платы и адреса записи; отдельный файл приложения нельзя произвольно писать по адресу 0.

Не реализованы: экономичный сон, измерение заряда аккумулятора, обновление по воздуху, мобильное приложение, второй этап со SMA. Физическая проверка датчика, вибрации и автономного питания остаётся следующим этапом.
